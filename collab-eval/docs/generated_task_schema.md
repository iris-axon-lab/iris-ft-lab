# Generated Task Schema

Tasks generated by `scripts/generate_tasks.py` follow this JSONL record format.
Each line is one JSON object.

---

## Record format

```json
{
  "case_id": "sc_gen_0042",
  "task_type": "spreadsheet_clean",
  "input": "<messy CSV string>",
  "expected_metadata": {
    "expected_row_count": 10,
    "required_columns": ["Quarter", "Revenue", "OpEx", "Headcount", "Notes"],
    "unit_normalization": {"forbidden_pattern": "\\$M|\\bM\\b"},
    "allowed_missing_fields": []
  },
  "gold_or_reference_output": "<clean CSV string>",
  "generation_seed": 42,
  "difficulty": "medium",
  "primary_dimension": "unit_consistency",
  "known_failure_modes": ["mixed_units", "units_hidden_in_notes"]
}
```

---

## Field descriptions

| Field | Type | Description |
|-------|------|-------------|
| `case_id` | string | Unique ID, format `sc_gen_{index:04d}` |
| `task_type` | string | Always `"spreadsheet_clean"` for Phase 1 |
| `input` | string | Messy CSV string the agent must clean |
| `expected_metadata` | object | Grading parameters (see below) |
| `gold_or_reference_output` | string | Clean CSV string (ground truth) |
| `generation_seed` | int | The `--seed` value used to generate this file |
| `difficulty` | string | `"easy"` \| `"medium"` \| `"hard"` |
| `primary_dimension` | string | Which grading dimension is most challenged |
| `known_failure_modes` | list[string] | Noise types seeded into this case |

### `expected_metadata` fields

| Field | Type | Description |
|-------|------|-------------|
| `expected_row_count` | int | Number of real data rows in the gold output (excluding header) |
| `required_columns` | list[string] | Column names the agent must preserve in output |
| `unit_normalization` | object | `{"forbidden_pattern": regex}` — pattern that must NOT appear in output |
| `allowed_missing_fields` | list[string] | Columns that may be absent without penalizing completeness |

---

## Grading from `expected_metadata`

The four deterministic grading dimensions for spreadsheet_clean map directly to
the metadata fields:

| Dimension | How to compute | Metadata field used |
|-----------|---------------|---------------------|
| `data_preservation` | `row_count_preserved(output, expected_row_count)` | `expected_row_count` |
| `format_validity` | `csv_parseable(output)` | — (no metadata needed) |
| `unit_consistency` | `unit_normalized(output, forbidden_pattern)` | `unit_normalization.forbidden_pattern` |
| `completeness` | `headers_preserved(output, required_columns)` | `required_columns` |

See `collab_eval/graders/deterministic.py` for function implementations.

---

## `primary_dimension` values

| Value | Primary challenge in this case |
|-------|-------------------------------|
| `data_preservation` | Messy input has blank rows, duplicate rows, or annotation rows |
| `unit_consistency` | Revenue/OpEx values use mixed `$M`/`$K` notation |
| `format_validity` | Input has annotation rows, extra whitespace, or malformed row widths |
| `completeness` | Input has renamed, missing, or extra columns |

---

## `known_failure_modes` values

| Mode | Description | Which dimension it probes |
|------|-------------|--------------------------|
| `blank_rows` | Blank lines interspersed in input | data_preservation |
| `duplicated_rows` | Some rows appear twice in input | data_preservation |
| `annotation_row` | Non-data row (e.g., units annotation) in input | data_preservation, format_validity |
| `extra_fabricated_rows` | Invented rows appended to input | data_preservation |
| `mixed_units` | Revenue/OpEx in mixed `$M`/`$K` notation | unit_consistency |
| `units_hidden_in_notes` | Original `$M` value stored in Notes free-text | unit_consistency |
| `mixed_unit_suffixes` | Some cells have explicit `$K` suffix | unit_consistency |
| `extra_whitespace` | Cells padded with spaces around commas | format_validity |
| `malformed_row_width` | Some rows have wrong number of columns | format_validity |
| `mid_table_separator` | A separator line (`---`) mid-table | format_validity |
| `notes_mostly_empty` | Notes column present but mostly blank | completeness |
| `extra_column` | Input has an extra column not in required schema | completeness |
| `extra_column_region` | Specifically, extra `Region` column | completeness |
| `renamed_revenue_column` | `Revenue` renamed to `Rev` in input | completeness |
| `renamed_notes_column` | `Notes` renamed to `Comment` in input | completeness |

## Coverage targets (verified post-generation)

For `--n 80 --seed 42`:

| primary_dimension | Target | Actual |
|-------------------|--------|--------|
| `data_preservation` | ≥ 20 | verified by generate_tasks.py |
| `unit_consistency` | ≥ 20 | verified by generate_tasks.py |
| `format_validity` + `completeness` | ≥ 20 combined | verified by generate_tasks.py |

---

## Determinism guarantee

Same `--seed` → same JSONL output, byte-for-byte.

Different `--seed` → different row counts, values, note text, noise positions,
and dimension/difficulty assignments. Coverage targets are still met for any
seed with `--n >= 80`.
